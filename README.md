The original dataset contains 114,546 hourly observations of 12 local climatological variables (such as temperature and wind speed) collected at JFK airport. This dataset can be obtained for free from the 
kaggle
.

OBJECTIVES
By completing this project, you will be able to:

Understand and explore the provided climatological datasets.

 Load and manage the datasets within the R environment.

Clean, process, and prepare weather data for analysis using R.

 Apply statistical and analytical techniques to examine precipitation patterns and related weather variables.

Interpret both historical and current weather data to generate meaningful insights for stakeholders


TASK INFORMATION

	1: Download and unzip the NOAA Weather Dataset. 

 	2: Read the dataset into the project. 

 	3: Select the subset of columns. 

	4: Clean up columns. 

	5: Convert columns to numerical types. 

 	6: Rename data columns. 

	7: Perform exploratory data analysis. 

 	8: Apply linear regression. 

 	9: Improve the model. 

 	10: Find the best model.
